Mission Planner — Interface Overview

Mission Planner is a Windows ground control station for ArduPilot vehicles. Three tabs cover almost everything you'll do day to day.

Flight DataLive telemetry, HUD, map, and message console during flight.
Flight PlanDraw waypoints on the map and upload autonomous missions.
Config/TuningSet parameters, calibrate sensors, and tune PIDs.
Tip: connect over USB first for initial setup — save telemetry radio pairing for after the vehicle is calibrated and configured.

Typical first-session order

  1. Connect via USB, confirm firmware version in Config/Tuning
  2. Run the mandatory hardware setup wizard (frame, accel, compass, radio)
  3. Set failsafes and flight modes
  4. Switch to Flight Data and verify sensor readings on the bench
