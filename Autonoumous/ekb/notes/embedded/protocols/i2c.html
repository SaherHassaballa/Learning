I2C Protocol Fundamentals

I2C (Inter-Integrated Circuit) is a two-wire synchronous serial bus used to connect low-speed peripherals — IMUs, barometers, EEPROMs — to a microcontroller.

MCU ──SDA──●──●──● (data, open-drain, pulled up) ──SCL──●──●──● (clock, open-drain, pulled up) │ │ │ Sensor A Sensor B Sensor C (each with a unique address)

Key properties

Wires2 (SDA + SCL), plus ground TopologyMulti-drop bus — many devices share the same two lines Addressing7-bit (or 10-bit) device address sent by the master Typical speed100 kHz (standard), 400 kHz (fast mode), 1 MHz+ (fast mode+) Pull-upsRequired on SDA and SCL — lines are open-drain

Clock stretching

A slow slave device can hold SCL low to pause the master mid-transaction. Not all microcontroller I2C peripherals support this correctly — worth checking datasheets when a sensor read intermittently hangs.

Common pitfalls

  • Missing or too-weak pull-up resistors → corrupted or stuck bus
  • Two devices sharing the same fixed address → use an I2C mux or a device with an ADDR pin
  • Long wires at high bus speed → drop to 100 kHz or add a bus buffer
